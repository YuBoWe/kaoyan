### 1. 计算机网络
#### 1.1 为什么 IP 地址又称为虚拟地址
- **软件维护与逻辑属性**：IP 地址由网络层软件（协议栈）维护和分配，并非像 MAC 地址那样固化在硬件（网卡）中，是一个逻辑上的标识而非物理存在的地址。
- **屏蔽异构网络差异**：IP 协议在各种物理层和数据链路层不同的异构网络之上，利用软件抽象出了一张统一的逻辑（虚拟）IP 网络。作为该虚拟网络中的寻址标识，IP 地址自然也是“虚拟”的。
- **逻辑寻址与物理交付解耦**：IP 地址仅用于网络层的逻辑路由寻址；当数据进入具体物理链路传输时，必须通过 ARP 等协议将其转换为实际的硬件地址（MAC 地址）才能完成交付。

#### 1.2 简述 RIP、OSPF 和 BGP 路由选择协议的主要特点
1. **RIP 协议（基于距离向量，用于 IGP）**
   - 和谁交换：仅与相邻路由器交换信息。
   - 交换什么：当前路由器知道的全部信息（即自己的完整路由表）。
   - 何时交换：按固定时间间隔（如 30 秒）周期性交换，或拓扑变化时及时通告。
2. **OSPF 协议（基于链路状态，用于 IGP）**
   - 和谁交换：用洪泛法向本自治系统（AS）内的所有路由器发送信息。
   - 交换什么：与本路由器相邻路由器的链路状态（即“代价/度量”）。
   - 何时交换：仅当链路状态发生变化时才发送信息。
3. **BGP 协议（基于路径向量，用于 EGP）**
   - 交换内容：自治系统（AS）之间交换可达性信息（路径向量，即到达目的网络需经过的 AS 列表）。
   - 选择策略：路由选择必须考虑安全、政治等策略因素。
   - 寻优目标：寻找一条无环且较好的路由，而非绝对的最佳路由。

#### 1.3 RIP 使用 UDP，OSPF 使用 IP，而 BGP 使用 TCP，这样做有什么优点？为什么 RIP 周期性地和临站交换路由信息而 BGP 不这样做
- **选用传输协议的优点**：
  - **RIP (UDP)**：开销小、协议简单。
  - **OSPF (IP)**：省去传输层首部，开销更小、效率更高。
  - **BGP (TCP)**：提供可靠传输，保障大路由表高效交付。
- **是否周期交换的原因**：
  - **RIP**：基于不可靠的 UDP，必须周期交换以保证更新与容错。
  - **BGP**：基于可靠的 TCP，初始全量交换后只需触发更新（增量），节省带宽。

### 2. 数据结构 (动态规划 DP 专题)

#### 2.1 走格子，拿最大收益，一次瞬移(i, j)到(i+1, j+1)，有负权值，只能向右或者向下
- **核心思想**：维护 2 页状态（`dp[N][M][2]`），第 0 页表示未发生瞬移，第 1 页表示已发生 1 次对角线瞬移。
- **算法实现**：
```c
Algorithm SEU_DiagonalJump_Compact(Grid, N, M):
    // 1. 初始化两页小抄，全部铺满 -∞
    定义 dp[N][M][2] = {-∞}
    
    // 起点
    dp[0][0][0] = Grid[0][0]
    dp[0][0][1] = -∞ 
    
    // 2. 初始化第一行 (只能向右，无法发生对角线瞬移)
    FOR j = 1 TO M-1 DO:
        dp[0][j][0] = dp[0][j-1][0] + Grid[0][j]
        dp[0][j][1] = -∞ 
    END FOR
    
    // 3. 初始化第一列 (只能向下，无法发生对角线瞬移)
    FOR i = 1 TO N-1 DO:
        dp[i][0][0] = dp[i-1][0][0] + Grid[i][0]
        dp[i][0][1] = -∞
    END FOR
    
    // 4. 核心状态转移
    FOR i = 1 TO N-1 DO:
        FOR j = 1 TO M-1 DO:
            // 第 0 页：纯路人，没用过瞬移，只能从上面或左边来
            dp[i][j][0] = max(dp[i-1][j][0], dp[i][j-1][0]) + Grid[i][j]
            
            // 第 1 页：瞬移者，三种情况（继承上面、继承左边、此时此地发动对角线瞬移）
            dp[i][j][1] = max(dp[i-1][j][1], dp[i][j-1][1], dp[i-1][j-1][0]) + Grid[i][j]
        END FOR
    END FOR
    
    // 5. 大结局
    RETURN max(dp[N-1][M-1][0], dp[N-1][M-1][1])
```

#### 2.2 最后一块石头的最小重量 (0-1 背包变体)
- **核心转换**：两两相减等价于将石头分为 A、B 两堆，目标是使两堆重量尽可能接近总重量的一半 `Target = sum / 2`。
- **算法实现**：
```c
Algorithm LastStoneWeightII(stones):
    N = length(stones)
    sum = 0
    FOR i = 1 TO N DO:
        sum = sum + stones[i]
    END FOR
    Target = sum / 2
    
    定义二维整数数组 dp[N+1][Target+1] = {0}
    
    FOR i = 1 TO N DO:
        FOR j = 1 TO Target DO:
            IF stones[i] > j THEN
                dp[i][j] = dp[i-1][j]
            ELSE
                dp[i][j] = max(dp[i-1][j], stones[i] + dp[i-1][j - stones[i]])
            END IF
        END FOR
    END FOR
    
    max_weight = dp[N][Target]
    RETURN sum - 2 * max_weight
```

#### 2.3 零钱兑换 (完全背包 - 最少硬币数)
- **核心逻辑**：完全背包物品可无限次选择，状态转移为 `dp[i][j] = min(dp[i - 1][j], dp[i][j - coins[i]] + 1)`。
- **算法实现**：
```c
Algorithm CoinChange_2D(coins, amount):
    N = length(coins)
    定义二维整数数组 dp[N+1][amount+1] = {amount + 1}
    FOR i = 0 TO N DO:
        dp[i][0] = 0
    END FOR
    
    FOR i = 1 TO N DO:
        FOR j = 1 TO amount DO:
            IF coins[i] > j THEN
                dp[i][j] = dp[i - 1][j]
            ELSE
                dp[i][j] = min(dp[i - 1][j], dp[i][j - coins[i]] + 1)
            END IF
        END FOR
    END FOR
    
    IF dp[N][amount] == amount + 1 THEN
        RETURN -1
    ELSE
        RETURN dp[N][amount]
    END IF
```

#### 2.4 完全平方数 (完全背包 - 凑成 n 的最少平方数)
- **核心逻辑**：物品为 $1^2, 2^2, \dots, M^2$（其中 $M = \lfloor\sqrt{n}\rfloor$），背包容量为 $n$。
- **算法实现**：
```c
Algorithm NumSquares_2D(n):
    M = floor(sqrt(n))
    定义二维整数数组 dp[M + 1][n + 1] = {n + 1}
    FOR i = 0 TO M DO:
        dp[i][0] = 0
    END FOR
    
    FOR i = 1 TO M DO:
        weight = i * i
        FOR j = 1 TO n DO:
            IF weight > j THEN
                dp[i][j] = dp[i - 1][j]
            ELSE
                dp[i][j] = min(dp[i - 1][j], dp[i][j - weight] + 1)
            END IF
        END FOR
    END FOR
    
    RETURN dp[M][n]
```

### 3. 计算机组成原理与操作系统重点梳理

#### 3.1 计算机组成原理
- **硬布线 vs 微程序控制器**：
  - 硬布线控制器：基于组合逻辑电路，速度快、结构繁琐，扩充困难。
  - 微程序控制器：将微指令存储在控制存储器（CM）中，通过执行微程序产生微命令，易于扩展和修改。
- **微指令编码方式**：
  - 直接编码（不译码）：操作控制字段每位对应一个微命令，并行性好、速度快、微指令长。
  - 字段直接编码（显式译码）：将互斥微命令分在同一字段，译码后产生控制信号。
  - 字段间接编码（隐式译码）：需由另一字段的微命令解释。
- **微指令格式**：水平型微指令（并行度高、字长长）与垂直型微指令（结构简单、并行度低）。

#### 3.2 操作系统
- **打开与关闭文件系统调用**：
  - `open()`：在磁盘检索文件的 FCB，并将其复制到内存已打开文件表，返回文件描述符，避免重复搜盘。
  - `close()`：清理内存表项，若文件修改则将更新后的控制信息（Inode/FCB）写回磁盘。
- **程序链接与装入方式**：
  - **链接**：静态链接（装入前）、装入时动态链接（边装入边链接）、运行时动态链接（需要时才链接）。
  - **装入**：绝对装入（单道环境）、可重定位装入（静态重定位，装入时一次性改写物理地址）、动态运行时装入（动态重定位，借助重定位寄存器在执行时转换地址）。

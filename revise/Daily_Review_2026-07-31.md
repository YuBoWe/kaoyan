6. 操作系统
- 打开文件系统调用 `open()` 的本质。`open()` 系统调用的主要目的是为了避免每次读写文件时都去频繁检索磁盘目录。它会在磁盘上找到文件的目录项（FCB），并将该目录项复制到内存中的已打开文件表（FCB链表/表项）中。后续的读写操作就可以直接通过内存中的索引（文件描述符）进行，从而大大提高效率。
  - **B 选项**：复制整个文件到内存属于读文件（`read`）或文件装载，并非打开文件的目的。
  - **C 选项**：在磁盘寻找目录项只是 `open()` 的中间步骤，不是其“主要工作/主要目的”。
  - **D 选项**：文件在打开之前是在磁盘（外存）上的，并非在内存中
- 关闭文件系统调用 `close()` 的主要工作。
  - 当文件使用完毕被关闭时，系统需要清理内存中的相关资源。若文件在打开期间被修改过，系统需要**将文件当前的控制信息（即内存中的 FCB / 索引节点 Inode 信息）写回磁盘**，更新磁盘上的元数据，并回收该文件在打开文件表中占用的内存表目。
- 超级块保存的是整个文件系统的全局引导与结构信息，不是单个文件关闭时的操作对象。
- FAT32 文件系统的目录项结构
  - **A（文件名）** 与 **D（文件所在的物理位置/起始簇号）**：均为 FAT32 目录项中必须包含的基础信息。
  - **B（文件访问权限说明）：** **FAT32 不包含此项**。FAT32 设计较早期，没有 Unix/Linux 的 `rwx` 权限控制，也不支持 NTFS 的 ACL（访问控制列表），仅支持简单的文件属性（只读、隐藏、系统、归档等）。
- 文件系统保护机制.文件保护机制主要是为了防止文件被非法读取、修改或破坏，经典手段包括：**口令保护（A）**、**存取控制（B）**、**用户权限表（C）** 以及加密等。
- 文件安全管理的四级防护。
  - **系统级安全（A）：** 任何用户进入系统前必须通过注册/登录验证（如输入用户名和密码），只有合法用户才能进入系统。- **用户级安全（C）：** 根据用户身份（文件所有者、同组用户、其他用户）划分存取权限。**目录级安全（B）：** 限制用户对目录的访问（如搜索、列出目录内容）。**文件级安全（D）：** 针对单个文件设置的具体访问控制列表（ACL）或属性。
- 文件系统性能优化与 I/O 设备调度的区别。
  - **A（目录项分解）：** 如 Unix 采用 Inode 机制，将文件名与文件描述符分离，大幅减小目录项体积，增加一个磁盘块能容纳的目录项数量，从而显著减少查找文件时的磁盘 I/O 次数，是**文件系统层**的经典性能优化。**B（文件高速缓存）：** 将频繁读写的文件块缓存在内存中，减少物理磁盘访问，提升**文件系统**性能。**D（异步 I/O）：** 允许系统发起 I/O 后不阻塞，提高 CPU 与文件系统的并发效率。**C（磁盘调度算法）：** 如 FSCAN、C-LOOK 等，属于**底层 I/O 硬件/磁盘设备管理**的调度策略（用于优化磁头寻道时间），并不属于文件系统本身的结构与算法操作。

### 1. 数据结构 (算法)
#### 1.1 输出 Vi 到 Vj 之间长度为 m 的简单路径
```c
void DFS(Graph G, int i, int j, int visit[], int path[], int *top, int m) {
    visit[i] = 1;
    path[++(*top)] = i;

    if (i == j && (*top) == m) {
        for (int k = 0; k <= *top; k++)
            printf("%d ", path[k]);
        printf("\n");
    }

    Node p = G.adjlist[i].firstarc;
    for (; p != NULL; p = p->nextarc)
        if (visit[p->adjvex] == 0)
            DFS(G, p->adjvex, j, visit, path, top, m);

    --(*top);
    visit[i] = 0;
} //时空复杂度分别为 O(V+E) 和 O(V)
```

#### 1.2 求不带权的无/有向图中 v 顶点到其他顶点的最短路径（长度），存储到 dist 数组中
```c
void BFS(Graph G, int v, int dist[]) {
    int visit[maxsize] = {0};
    for (int i = 0; i < G.numver; i++)
        dist[i] = INT16_MAX;
    int que[maxsize];
    int front = 0, rear = 0;
    visit[v] = 1;
    dist[v] = 0;
    que[++rear] = v;
    while (front != rear) {
        v = que[++front];
        Node p = G.adjlist[v].firstarc;
        for (; p != NULL; p = p->nextarc)
            if (visit[p->adjvex] == 0) {
                visit[p->adjvex] = 1;
                que[++rear] = p->adjvex;
                dist[p->adjvex] = dist[v] + 1;
            }
    }
} //时空复杂度分别为 O(V+E) 和 O(V)
```

### 2. 计算机网络
#### 2.1 ARP 高速缓存超时计时器与免 ARP 请求场景
- **(1) 设置 10～20 分钟超时计时器的原因及过长/过短的影响**：
  - 原因：网络中主机可能更换网卡或变更 IP 地址，设置超时计时器是为了及时更新 ARP 高速缓存中的地址映射关系。
  - 太短的问题：ARP 请求和响应分组发送过于频繁，增加网络通信开销（增加广播流量）。
  - 太长的问题：映射关系改变后，旧的错误缓存无法及时更新，导致主机长时间无法正常通信。
- **(2) 不需要发送 ARP 请求分组的情况**：
  - 缓存命中：源主机的 ARP 高速缓存中已有该目的 IP 地址的映射项目。
  - 广播分组：源主机发送的是广播分组（目的 MAC 地址为全 1）。
  - 点对点链路：源主机与目的主机之间使用的是点对点链路（如 PPP 协议，不需要 MAC 地址）。

#### 2.2 IP 层查找路由算法
- **核心 4 步算法**：
  1. 提取地址：从 IP 数据报首部提取目的 IP 地址 D。
  2. 特定主机路由：若转发表中有目的地址为 D 的特定主机路由，则直接按其下一跳转发；否则执行下一步。
  3. 掩码与运算（最长前缀匹配）：将 D 与转发表各行的子网掩码逐行按位进行 与（AND）运算。若结果与该行网络前缀匹配，则按指定的下一跳/接口转发；否则继续检查下一行。
  4. 默认路由与出错处理：若所有前缀均不匹配，检查是否有默认路由；有则发往默认路由器，无则丢弃分组并报告出错（发送 ICMP 差错报文）。
- **口诀**：一提（目的IP）→ 二查（主机路由）→ 三与（掩码与运算/最长匹配）→ 四默认/报错。

#### 2.3 IGP 和 EGP 协议的主要区别
- **作用范围不同**：
  - IGP（内部网关协议）：用于同一个自治系统（AS）内部的路由选择。
  - EGP（外部网关协议）：用于不同自治系统（AS）之间传递路由选择信息。
- **侧重点不同**：
  - IGP：侧重于寻找自治系统内部的最佳路径（计算效率）。
  - EGP：侧重于自治系统之间的路由可达性与安全策略（路径向量/策略控制）。
- **代表协议不同**：
  - IGP 常见协议：RIP、OSPF。
  - EGP 常见协议：BGP（如 BGP-4）。

#### 2.4 名词解释
1. **协议栈**：指计算机网络分层结构中，各层协议按顺序组合在一起的结构（因画起来像堆栈而得名）。
2. **实体**：任何可以发送或接收信息的硬件或软件进程（或特定的软件模块）。
3. **对等层**：在网络体系结构中，通信双方实现相同功能的对应层（如 A 的第 n 层和 B 的第 n 层）。
4. **协议数据单元 (PDU)**：对等实体之间进行信息交换的数据单元。
5. **服务访问点 (SAP)**：在同一系统中，相邻两层的实体进行交互（交换信息）的逻辑接口/地方。
6. **客户 (Client)**：网络通信中，应用进程里的服务请求方（主动发起通信）。
7. **服务器 (Server)**：网络通信中，应用进程里的服务提供方（被动等待并响应通信的机器或程序）。
8. **客户-服务器方式 (C/S方式)**：描述进程之间服务请求与服务提供的一种网络架构关系。特点是客户主动请求、服务器被动接收，连接建立后可进行双向通信。

### 3. 动态规划
#### 3.1 组合总和 Ⅳ (排列数 vs 组合数)
- **题目简述**：给定不同整数数组 `nums` 和目标整数 `target`，找出总和为 `target` 的元素组合个数。顺序不同视作不同组合（求排列数）。
- **核心逻辑**：
  - **求组合数（外层物品，内层容量）**：先遍历硬币，天然去重。
  - **求排列数（外层容量，内层物品）**：先遍历容量，每个容量下尝试所有数字，包含所有顺序。
  - **底层逻辑等价于爬楼梯**：`target` 为楼梯总级数，`nums` 为每次能跨的步数。

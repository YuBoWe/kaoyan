## 网格

1.在一个 $N \times M$ 的网格迷宫中，每个房间都放有一定数量的金币，金币数量由二维数组 `Grid[N][M]` 给出。一个探险家从左上角 `(0, 0)` 出发，目标是到达右下角 `(N-1, M-1)`。探险家每次**只能向右**或**向下**移动一步。

请设计一个算法，求出探险家到达终点时能收集到的最大金币总数。要求：

1. 写出算法的核心思想与状态转移方程。
2. 用伪代码实现该算法。
3. 分析算法的时间复杂度和空间复杂度。

```c
Algorithm MaxCoinsPath(Grid, N, M):
    // 1. 数据结构初始化 (Initialization)
    定义一个大小为 N x M 的二维数组 dp[N][M]
    将 dp 数组的所有元素初始化为 0
    
    // 初始化起点
    dp[0][0] = Grid[0][0]
    
    // 初始化第一行 (仅受左边影响)
    FOR j = 1 TO M-1 DO:
        dp[0][j] = dp[0][j-1] + Grid[0][j]
    END FOR
    
    // 初始化第一列 (仅受上面影响)
    FOR i = 1 TO N-1 DO:
        dp[i][0] = dp[i-1][0] + Grid[i][0]
    END FOR
    
    // 2. 状态转移计算 (State Transition)
    // 从行索引 1 和 列索引 1 开始，计算剩余所有网格
    FOR i = 1 TO N-1 DO:
        FOR j = 1 TO M-1 DO:
            // 比较从上方下来和从左方过来的金币数，取最大值并加上当前房间的金币
            dp[i][j] = max(dp[i-1][j], dp[i][j-1]) + Grid[i][j]
        END FOR
    END FOR
    
    // 3. 返回最终结果
    RETURN dp[N-1][M-1]
```

**时间复杂度：** 算法使用两层嵌套循环遍历整个 $N \times M$ 网格，每次状态转移计算只需要常数时间 $O(1)$。因此，总时间复杂度为 **$O(N \times M)$**。

**空间复杂度：** 算法额外开辟了一个大小为 $N \times M$ 的二维数组 $dp$ 来存储中间状态。因此，空间复杂度为 **$O(N \times M)$**。（*注：如使用滚动数组进行空间优化，可将空间复杂度降为 $O(M)$*）





2.假设你要去参加研究生的复试，考场在顶楼。你面前有一段共有 $N$ 阶的楼梯。 由于你背着沉重的书包，你每次跨步**只能选择向上走 1 阶，或者走 2 阶**。 请问：你从平地（第 0 阶）爬到第 $N$ 阶，总共有多少种不同的走法？

```c
Algorithm ClimbStairs(N):
    // 1. 边界处理
    IF N == 1 THEN RETURN 1
    IF N == 2 THEN RETURN 2
    
    // 2. 初始化作弊小抄 (dp 数组)
    定义一维数组 dp[N+1]
    dp[1] = 1
    dp[2] = 2
    
    // 3. 状态转移计算
    FOR i = 3 TO N DO:
        // 核心逻辑：当前阶数 = 上一阶 + 上两阶
        dp[i] = dp[i-1] + dp[i-2]
    END FOR
    
    // 4. 返回终点
    RETURN dp[N]
```





3.考场楼梯变成了收费制。每阶台阶上都有一个收费站，价格由数组 `cost[i]` 给出。

- 规则 1：你依然每次只能向上爬 **1 阶** 或 **2 阶**。
- 规则 2：你一旦站上第 $i$ 阶，就要交钱 `cost[i]` 才能继续往上走。
- 目标：求爬到楼顶（即跨过最后一阶台阶）的**最小总花费**。

```c
Algorithm MinCostClimbingStairs(cost, N):
    // cost 是长度为 N 的数组，代表 0 到 N-1 阶的费用
    // N 代表楼顶（即跨过所有台阶）

    // 1. 特判与边界初始化 (Initialization)
    IF N == 0 THEN RETURN 0
    IF N == 1 THEN RETURN cost[0]
    
    定义一维数组 dp[N]
    dp[0] = cost[0]
    dp[1] = cost[1]
    
    // 2. 状态转移计算 (State Transition)
    FOR i = 2 TO N-1 DO:
        // 核心逻辑：从前两阶中挑一个便宜的，加上自己这一阶的钱
        dp[i] = min(dp[i-1], dp[i-2]) + cost[i]
    END FOR
    
    // 3. 返回登顶结果
    // 注意：楼顶是在 N 阶之上，意味着你可以从第 N-1 阶跳上来，也可以从第 N-2 阶跳上来
    // 到达楼顶不需要再交钱了，所以最后一步就是纯粹比较谁更便宜
    RETURN min(dp[N-1], dp[N-2])
```



4.在一个 $N \times M$ 的网格化安全隔离区中，每个节点代表一个路由器。

你需要把一个机密数据包从左上角起点 $(0,0)$ 传输到右下角终点 $(N-1, M-1)$。

每个路由器节点在处理数据包时，都有被敌方侦测到的风险，我们用一个二维数组 `Risk[i][j]` 来表示经过第 $i$ 行、第 $j$ 列路由器的**暴露风险值**。

为了兼顾隐蔽和效率，数据包的路由规则如下：

1. 它可以向**右**传给下一个路由器。
2. 它可以向**下**传给下一个路由器。
3. **（新增特权）** 它还可以直接向右下方（对角线）传给下一个路由器（即从 $(x, y)$ 直接跳到 $(x+1, y+1)$）。

**目标：** 找出一条从起点到终点的路径，使得整个传输过程的**总暴露风险值最小**。

```c
Algorithm MinRiskPath(Risk, N, M):
    // 1. 初始化阶段 (Initialization)
    定义一个大小为 N x M 的二维数组 dp[N][M]
    
    // 初始化起点
    dp[0][0] = Risk[0][0]
    
    // 初始化第一行：数据包只能一直向右传
    FOR j = 1 TO M-1 DO:
        dp[0][j] = dp[0][j-1] + Risk[0][j]
    END FOR
    
    // 初始化第一列：数据包只能一直向下传
    FOR i = 1 TO N-1 DO:
        dp[i][0] = dp[i-1][0] + Risk[i][0]
    END FOR
    
    // 2. 状态转移阶段 (State Transition)
    // 从第1行、第1列开始，此时每个节点都有完整的三个方向(上、左、左上)可以参考
    FOR i = 1 TO N-1 DO:
        FOR j = 1 TO M-1 DO:
            // 找出三个历史来源中的最小风险值
            min_prev = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])
            // 加上当前节点的风险值
            dp[i][j] = min_prev + Risk[i][j]
        END FOR
    END FOR
    
    // 3. 返回最终结果
    RETURN dp[N-1][M-1]
```

**时间复杂度：** 算法主要包含两个单独的边界初始化循环，以及一个嵌套的双层循环遍历剩余节点。每个节点的状态计算只需常数时间 $O(1)$，总共计算 $N \times M$ 个节点，因此总时间复杂度为 **$O(N \times M)$**。

**空间复杂度：** 算法额外开辟了一个大小为 $N \times M$ 的二维数组来保存中间状态，因此空间复杂度为 **$O(N \times M)$**。



5.在一个 $N \times M$ 的网格迷宫中，探险家从左上角 `(0, 0)` 走到右下角 `(N-1, M-1)`，只能向右或向下走。 但这次迷宫里有**石头（障碍物）**。如果网格 `Grid[i][j] == 1`，表示这里是平地，走过去能拿到 1 个金币；如果 `Grid[i][j] == 0`，表示这里是**石头**，根本无法进入。 求到达终点能收集到的**最大金币数**（如果根本走不到终点，返回 0）。

```c
Algorithm MaxCoinsWithObstacles(Grid, N, M):
    // 0. 极端情况特判
    IF Grid[0][0] == 0 THEN RETURN 0  // 起点就是石头，直接下班
    
    定义二维数组 dp[N][M]，全部初始化为 0
    dp[0][0] = Grid[0][0]
    
    // 1. 初始化第一行 (注意连锁反应！)
    FOR j = 1 TO M-1 DO:
        IF Grid[0][j] == 0 THEN 
            BREAK  // 遇到石头，后面的路全堵死了，保持默认的 0 即可，直接跳出循环
        ELSE
            dp[0][j] = dp[0][j-1] + Grid[0][j]
    END FOR
    
    // 2. 初始化第一列 (同理，向下遇到石头就停止)
    FOR i = 1 TO N-1 DO:
        IF Grid[i][0] == 0 THEN
            BREAK  // 遇到石头，下面的路全堵死了
        ELSE
            dp[i][0] = dp[i-1][0] + Grid[i][0]
    END FOR
    
    // 3. 核心状态转移
    FOR i = 1 TO N-1 DO:
        FOR j = 1 TO M-1 DO:
            IF Grid[i][j] == 0 THEN
                dp[i][j] = 0  // 进不去，记为0
            ELSE
                // 如果左边或上面是石头，它们的 dp 值本来就是 0，所以用 max 不受影响
                dp[i][j] = max(dp[i-1][j], dp[i][j-1]) + Grid[i][j]
        END FOR
    END FOR
    
    RETURN dp[N-1][M-1]
```

**规则：** 机器人每次只能向**右**走一步，或者向**下**走一步。

**问题：** 机器人从起点走到终点，总共有**多少条不同的路线**？

```c
Algorithm UniquePaths(N, M):

    定义二维数组 dp[N][M]

    FOR j = 0 TO M-1 DO:

            dp[i][j] = dp[i-1][j] + dp[i][j-1]

    END FOR

    RETURN dp[N-1][M-1]
```

7.你在玩一个跳伞寻宝游戏。地图依然是一个 $N \times N$ 的网格，每个房间都有数量不等的金币 `Grid[i][j]`。

- **规则 1（任意起飞）：** 游戏开始时，你可以选择降落在 **第一行（第 0 行）** 的任意一个房间作为起点。
- **规则 2（重力限制）：** 降落后，你每次只能向 **正下方 `(i+1, j)`** 走，或者向 **右下方 `(i+1, j+1)`** 走。
- **目标：** 一路走到最后一行，找出能拿到最多金币的路线。

```c
Algorithm MaxFallingGold(Grid, N, M):
    // N 是行数，M 是列数
    定义二维数组 dp[N][M]
    
    // 1. 初始化第一行 (因为可以降落在第一行的任意房间)
    FOR j = 0 TO M-1 DO:
        dp[0][j] = Grid[0][j]
    END FOR
    
    // 2. 核心状态转移 (从第 1 行开始向下逐层降落)
    FOR i = 1 TO N-1 DO:
        FOR j = 0 TO M-1 DO:
            // 处理边界：贴着最左边跳，没有“左上方”这个选项
            IF j == 0 THEN
                dp[i][j] = dp[i-1][j] + Grid[i][j]
            ELSE
                // 正常情况：比较“正上方”和“左上方”谁更大
                dp[i][j] = max(dp[i-1][j], dp[i-1][j-1]) + Grid[i][j]
            END IF
        END FOR
    END FOR
    
    // 3. 在最后一行寻找全局最大值
    // 因为你可以走到最后一行的任意一个房间结束
    max_ans = dp[N-1][0]   // 先假设最左下角的数字是最大的
    FOR j = 1 TO M-1 DO:
        IF dp[N-1][j] > max_ans THEN
            max_ans = dp[N-1][j]  // 遇到更大的就更新
    END FOR
    
    RETURN max_ans
```



8.在一个 $N \times M$ 的迷宫里，你要从起点 `(0,0)` 走到终点 `(N-1, M-1)`，每次只能向右或向下走。

这次要求的是：**走到终点的“最少步数”**（每走一格算 1 步）。

- `Grid[i][j] == 0` 表示平地，可以正常走。
- `Grid[i][j] == 1` 表示坚固的墙壁，正常情况下绝对过不去。
- **【你的特权】**：你手里**有且仅有 1 枚高爆破甲弹**。在整个迷宫的探索中，你可以**炸毁任意 1 面墙壁**（强行跨过去）。

**问题：** 在拥有 1 枚炸弹的情况下，到达终点的最少步数是多少？（如果连炸弹都救不了你，返回 -1）。

```c
Algorithm MinStepsWithBomb(Grid, N, M):
    // 1. 初始化三维数组
    定义 dp[N][M][2]，全部初始化为 +∞
    
    // 起点初始化 (假设起点本身是平地)
    dp[0][0][0] = 0   // 站在起点不需要走，步数为 0
    dp[0][0][1] = +∞  // 还没走呢，不可能凭空用掉炸弹
    
    // 2. 初始化第一行 (只能一直向右走，看左边邻居的小抄)
    FOR j = 1 TO M-1 DO:
        IF Grid[0][j] == 0 THEN
            // 平地：继承同维度的历史
            dp[0][j][0] = dp[0][j-1][0] + 1
            dp[0][j][1] = dp[0][j-1][1] + 1
        ELSE
            // 墙壁：必须在这里用炸弹，继承第 0 页的历史
            dp[0][j][0] = +∞
            dp[0][j][1] = dp[0][j-1][0] + 1
        END IF
    END FOR
    
    // 3. 初始化第一列 (只能一直向下走，看上面邻居的小抄)
    FOR i = 1 TO N-1 DO:
        IF Grid[i][0] == 0 THEN
            dp[i][0][0] = dp[i-1][0][0] + 1
            dp[i][0][1] = dp[i-1][0][1] + 1
        ELSE
            dp[i][0][0] = +∞
            dp[i][0][1] = dp[i-1][0][0] + 1
        END IF
    END FOR
    
    // 4. 核心状态转移 (全向查抄)
    FOR i = 1 TO N-1 DO:
        FOR j = 1 TO M-1 DO:
            
            // 为了代码清爽，先把两个页面的“历史最优解”算出来
            min_prev_0 = min(dp[i-1][j][0], dp[i][j-1][0]) // 历史从没用过炸弹
            min_prev_1 = min(dp[i-1][j][1], dp[i][j-1][1]) // 历史已经用过炸弹
            
            IF Grid[i][j] == 0 THEN
                // 【当前是平地】：不用炸，直接平移继承
                dp[i][j][0] = min_prev_0 + 1
                dp[i][j][1] = min_prev_1 + 1
            ELSE
                // 【当前是墙壁】：高光时刻！跨页查抄！
                dp[i][j][0] = +∞                // 没炸弹就死路一条
                dp[i][j][1] = min_prev_0 + 1    // 炸碎它！消耗一次机会
            END IF
            
        END FOR
    END FOR
    
    // 5. 结算大结局
    // 能到达终点的最少步数，是“没用过炸弹”和“用过炸弹”两条时间线里的赢家
    ans = min(dp[N-1][M-1][0], dp[N-1][M-1][1])
    
    IF ans >= +∞ THEN
        RETURN -1  // 悲剧：两页小抄都是无穷大，说明炸弹都不够用，走不到终点
    ELSE
        RETURN ans
```



9.你在玩吃金币游戏，只能向右或向下走。求到达终点的**最大收益**。

- 平地 `Grid[i][j]` 是正数（金币）。
- 毒气室 `Grid[i][j]` 是负数（扣分，比如 -10）。
- 铁墙 `Grid[i][j]` 极其坚固，**绝对无法通行**。

```
Algorithm MaxProfitWithTraps(Grid, N, M):
    // 0. 特殊情况判断
    // 如果起点或者终点就是铁墙，直接返回无解
    IF Grid[0][0] 是铁墙 OR Grid[N-1][M-1] 是铁墙 THEN 
        RETURN -无穷
    
    // 1. 定义二维数组
    // 全部初始化为 -无穷，这是一种非常保险的兜底策略
    定义二维数组 dp[N][M]，初始值全设为 -无穷
    
    // 起点初始化
    dp[0][0] = Grid[0][0]
    
    // 2. 初始化第一行 (只能向右走)
    FOR j = 1 TO M-1 DO:
        IF Grid[0][j] 是铁墙 THEN
            BREAK // 遇到铁墙直接停止，后面的格子保持 -无穷 的初始值，彻底封死
        ELSE
            dp[0][j] = dp[0][j-1] + Grid[0][j]
    END FOR
    
    // 3. 初始化第一列 (只能向下走)
    FOR i = 1 TO N-1 DO:
        IF Grid[i][0] 是铁墙 THEN
            BREAK // 同理，遇到铁墙，下面的路彻底封死
        ELSE
            dp[i][0] = dp[i-1][0] + Grid[i][0]
    END FOR
    
    // 4. 核心状态转移
    FOR i = 1 TO N-1 DO:
        FOR j = 1 TO M-1 DO:
            IF Grid[i][j] 是铁墙 THEN
                // 核心防线：用 -无穷 剥夺铁墙的竞争资格
                dp[i][j] = -无穷
            ELSE
                // 如果左边和上面都是 -无穷（即被铁墙包围的死胡同），
                // max 算出来也是 -无穷，加上当前 Grid 值后依然极小，符合物理逻辑
                dp[i][j] = max(dp[i-1][j], dp[i][j-1]) + Grid[i][j]
            END IF
        END FOR
    END FOR
    
    // 5. 结果判断
    ans = dp[N-1][M-1]
    IF ans <= -9999999 THEN // 假设 -9999999 足够代表 -无穷
        RETURN "无法到达终点"
    ELSE
        RETURN ans
```

## 0-1背包

1.你背着一个最大承重为 $W$ 的背包。

宝库里有 $N$ 个物品排成一排。每个物品有两个属性：

- **重量** $w[i]$（占多少空间）
- **价值** $v[i]$（值多少钱）

你的目标是：在不超过背包承重 $W$ 的前提下，装走价值最大的物品组合。每个物品只有一件，你要么装（1），要么不装（0）。

$dp[i][j]$ 的终极含义是： **面对前 $i$ 个物品，在背包容量刚好为 $j$ 的限制下，你能装出的最大总价值。**

```c
Algorithm ZeroOneKnapsack(w, v, N, W):
    // w 是重量数组，v 是价值数组，假设下标从 1 开始到 N
    // N 是物品总数，W 是背包最大承重
    
    // 1. 初始化 DP 表格 (由于是 0 开始，大小需开 N+1 行，W+1 列)
    // 默认全填 0 即可，天然满足了第 0 行和第 0 列全为 0 的边界条件
    定义二维数组 dp[N+1][W+1] = {0}
    
    // 2. 核心状态转移
    // i 代表当前正在考虑第 i 个物品
    FOR i = 1 TO N DO:
        
        // j 代表当前假设的背包剩余容量 (从 1 遍历到最大容量 W)
        FOR j = 1 TO W DO:
            
            // 选项 A：这件物品太重了，目前的容量 j 根本装不下
            IF w[i] > j THEN
                // 只能选择不装，完全继承前 i-1 个物品在容量 j 下的最优解
                dp[i][j] = dp[i-1][j]
                
            // 选项 B：能装得下，进入终极二选一
            ELSE
                // 货比三家，取最大值
                dp[i][j] = max(dp[i-1][j]，v[i] + dp[i-1][j - w[i]])
            END IF
            
        END FOR
    END FOR
    
    // 3. 大结局
    // 站在最后一个物品面前，拥有最大容量 W 时，就是我们要的最终答案
    RETURN dp[N][W]
```



2.给你一个只包含正整数的非空数组 nums。请你判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

【示例 1】

输入： nums = [1, 5, 11, 5]输出： true解释： 数组可以分割成 [1, 5, 5] 和 [11]。

【示例 2】

输入： nums = [1, 2, 3, 5]输出： false解释： 数组不能分割成两个元素和相等的子集。

【数据范围】

1 <= nums.length <= 200

1 <= nums[i] <= 100

```c
Algorithm CanPartition(nums):
    // nums 是正整数数组，假设下标从 1 开始到 N
    N = length(nums)
    
    // 0. 前置计算：求数组元素总和
    sum = 0
    FOR i = 1 TO N DO:
        sum = sum + nums[i]
    END FOR
    
    // 如果总和为奇数，不可能平分为两个和相等的整数子集
    IF sum % 2 != 0 THEN
        RETURN false
    END IF
    
    Target = sum / 2
    
    // 1. 初始化 DP 表格 (大小开 N+1 行，Target+1 列)
    // 默认全填 false，dp[i][j] 表示前 i 个物品能否凑出恰好为 j 的和
    定义二维布尔数组 dp[N+1][Target+1] = {false}
    
    // 边界条件：目标和为 0 时，什么都不选即满足条件
    FOR i = 0 TO N DO:
        dp[i][0] = true
    END FOR
    
    // 2. 核心状态转移
    // i 代表当前正在考虑第 i 个数值
    FOR i = 1 TO N DO:
        
        // j 代表当前假设的目标和 (从 1 遍历到最大目标和 Target)
        FOR j = 1 TO Target DO:
            
            // 选项 A：这个数值太大了，当前的目标和 j 根本装不下
            IF nums[i] > j THEN
                // 只能选择不装，完全继承前 i-1 个元素在目标和 j 下的结果
                dp[i][j] = dp[i-1][j]
                
            // 选项 B：能装得下，二选一（只要有一个能凑成即可）
            ELSE
                // 逻辑“或”运算：不选当前数 OR 选当前数
                dp[i][j] = dp[i-1][j] OR dp[i-1][j - nums[i]]
            END IF
            
        END FOR
    END FOR
    
    // 3. 大结局
    // 站在最后一个元素面前，目标和恰好为 Target 时，就是我们要的最终答案
    RETURN dp[N][Target]
```



3.有一堆石头，每次从中选出任意两块石头粉碎。如果重量相同，两块都粉碎；如果不同，剩下重量为它们差值的石头。求最后最多剩下的一块石头的最小重量。

假设有四块石头 `a, b, c, d`。

不管你按什么顺序让它们相撞，本质上是在做**带括号的减法**。

比如先让 `a` 和 `b` 撞，剩下 `|a - b|`；再让 `c` 和 `d` 撞，剩下 `|c - d|`；最后让它们俩撞，结果是 `||a - b| - |c - d||`。

把绝对值展开，最终结果一定会变成这种形式：

**$(a + c) - (b + d)$**

也就是说，任意的碰撞过程，最终都可以等价于：**把所有石头分成两堆（设为 A 堆和 B 堆），然后让这两堆的总重量相减。**

要让最后的差值最小，这就等价于：**让 A 堆和 B 堆的重量尽可能接近，也就是尽可能都接近所有石头总重量的一半。**

**转化思路**：

不断地两两相减，本质上就是把所有石头分为两堆，一堆做加法，一堆做减法，让这两堆石头的总重量**尽可能接近**。

**背包模型**：

- **背包容量**：$Target = \lfloor \frac{sum}{2} \rfloor$ （总和的一半，向下取整）。
- **物品重量与价值**：石头的重量既是 $w[i]$ 也是 $v[i]$。
- **问题转化**：在容量为 $\lfloor \frac{sum}{2} \rfloor$ 的背包里，最多能装多少重量的石头？
- **最终答案**：假设背包最多装了 $max\_weight$。那么剩下的一堆石头重量是 $sum - max\_weight$。两者相减，最终剩下的最小石头重量就是 `(sum - max_weight) - max_weight` = `sum - 2 * max_weight`。



```c
Algorithm LastStoneWeightII(stones):
    // stones 是石头重量数组，假设下标从 1 开始到 N
    N = length(stones)
    
    // 0. 前置计算
    sum = 0
    FOR i = 1 TO N DO:
        sum = sum + stones[i]
    END FOR
    
    // 背包最大容量为总和的一半（自动向下取整）
    Target = sum / 2
    
    // 1. 初始化 DP 表格 (大小开 N+1 行，Target+1 列)
    // dp[i][j] 表示从前 i 块石头中选，在容量限制为 j 的情况下，能装入的最大重量
    定义二维整数数组 dp[N+1][Target+1] = {0}
    // 默认全填 0 即可，因为容量为 0 或 0 块石头时，能装的重量就是 0
    
    // 2. 核心状态转移
    FOR i = 1 TO N DO:
        FOR j = 1 TO Target DO:
            
            // 选项 A：第 i 块石头比当前背包容量 j 还重，装不下
            IF stones[i] > j THEN
                dp[i][j] = dp[i-1][j]
                
            // 选项 B：能装得下，抉择“装”还是“不装”，取最大值
            ELSE
                // 不装：dp[i-1][j]
                // 装：当前石头重量 + 剩余容量能装的最大重量
                dp[i][j] = max(dp[i-1][j], stones[i] + dp[i-1][j - stones[i]])
            END IF
            
        END FOR
    END FOR
    
    // 3. 计算大结局
    // dp[N][Target] 就是容量一半的背包最多能装的重量 (A堆)
    max_weight = dp[N][Target]
    
    // 返回两堆石头的差值
    RETURN sum - 2 * max_weight
```



4.目标和

给你一个非负整数数组 `nums` 和一个整数 `target` 。

向数组中的每个整数前添加 `'+'` 或 `'-'` ，然后串联起所有整数，可以构造一个**表达式**：

- 例如，`nums = [2, 1]` ，可以在 `2` 之前添加 `'+'` ，在 `1` 之前添加 `'-'` ，然后串联起来得到表达式 `"+2-1"` 。

返回可以通过上述方法构造的、运算结果等于 `target` 的不同**表达式的数目**。

【示例 1】

- **输入：** `nums = [1, 1, 1, 1, 1]`, `target = 3`
- **输出：** `5`
- **解释：** 一共有 5 种方法让最终目标和为 3。 `-1 + 1 + 1 + 1 + 1 = 3` `+1 - 1 + 1 + 1 + 1 = 3` `+1 + 1 - 1 + 1 + 1 = 3` `+1 + 1 + 1 - 1 + 1 = 3` `+1 + 1 + 1 + 1 - 1 = 3`

【示例 2】

- **输入：** `nums = [1]`, `target = 1`
- **输出：** `1`
- **解释：** 只有一种方法：`+1 = 1`



**状态定义**：`dp[i][j]` 表示从前 `i` 个数字中选，凑出目标和恰好为 `j` 的**方案数**。

**状态转移**：

- 如果装不下（`nums[i] > j`）：方案数只能继承之前的。`dp[i][j] = dp[i-1][j]`
- 如果装得下（`nums[i] <= j`）：总方案数 = **不装**当前物品的方案数 + **装**当前物品的方案数。
- 即：**`dp[i][j] = dp[i-1][j] + dp[i-1][j - nums[i]]`**

```c
Algorithm TargetSum(nums, target):
    // nums 是正非负数组，假设下标从 1 开始到 N
    N = length(nums)
    
    // 1. 前置计算
    sum = 0
    FOR i = 1 TO N DO:
        sum = sum + nums[i]
    END FOR
    
    // 边界拦截：如果目标和绝对值过大，或无法整除，直接无解
    IF abs(target) > sum OR (sum + target) % 2 != 0 THEN
        RETURN 0
    END IF
    
    P = (sum + target) / 2
    
    // 2. 初始化 DP 表格 (大小开 N+1 行，P+1 列)
    // 默认全填 0，dp[i][j] 表示前 i 个数字凑成和为 j 的方案数
    定义二维整数数组 dp[N+1][P+1] = {0}
    
    // 关键初始化：容量为 0 时，什么都不选就是 1 种合法的方案
    dp[0][0] = 1
    
    // 3. 核心状态转移
    FOR i = 1 TO N DO:
        
        // 🚨 陷阱警告：这里的 j 必须从 0 开始遍历，而不是从 1 开始
        FOR j = 0 TO P DO:
            
            IF nums[i] > j THEN
                dp[i][j] = dp[i-1][j]
            ELSE
                // 方案数累加（不再是 OR，也不再是 MAX）
                dp[i][j] = dp[i-1][j] + dp[i-1][j - nums[i]]
            END IF
            
        END FOR
    END FOR
    
    // 4. 大结局
    RETURN dp[N][P]
```

5.0和1

给你一个二进制字符串数组 `strs` 和两个整数 `m` 和 `n` 。

请你找出并返回 `strs` 的**最大子集**的大小，该子集中**最多**有 `m` 个 `0` 和 `n` 个 `1` 

```c
Algorithm OnesAndZeroes_3D(strs, m, n):
    // N 是字符串的总数量
    N = length(strs)
    
    // 1. 初始化三维 DP 表格
    // dp[i][j][k] 表示：只考虑前 i 个字符串，在最多有 j 个 0 和 k 个 1 时，最多能装的字符串个数
    // 维度大小：[N+1][m+1][n+1]，全部初始化为 0
    定义三维整数数组 dp[N+1][m+1][n+1] = {0}
    
    // 2. 核心状态转移
    // 外层循环：遍历每一个“物品”（前 i 个字符串）
    FOR i = 1 TO N DO:
        
        // 统计当前第 i 个字符串（注意数组下标可能是 i-1）所需的费用
        zeros = countZeros(strs[i]) 
        ones = countOnes(strs[i])   
        
        // 内层循环：遍历背包容量
        // 【核心优势】：因为有维度 i 的隔离，这里的 j 和 k 无论是正序还是逆序遍历，都完全可以！
        FOR j = 0 TO m DO:
            FOR k = 0 TO n DO:
                
                // 选项 A：当前的容量 j 或 k 不足以装下这个字符串
                IF j < zeros OR k < ones THEN
                    // 只能不装，直接照抄上一层（前 i-1 个字符串）的答案
                    dp[i][j][k] = dp[i-1][j][k]
                    
                // 选项 B：容量足够，抉择“装”还是“不装”
                ELSE
                    // 不装：dp[i-1][j][k]
                    // 装：1 + 扣除容量后，去【上一层】找最大数量，即 dp[i-1][j - zeros][k - ones]
                    dp[i][j][k] = max(dp[i-1][j][k], 1 + dp[i-1][j - zeros][k - ones])
                END IF
                
            END FOR
        END FOR
    END FOR
    
    // 3. 计算大结局
    // 考虑完所有 N 个字符串，拥有 m 个 0 和 n 个 1 时的最大数量
    RETURN dp[N][m][n]
```

```c
    // N 是物品种类数，W 是背包最大容量
    // w 是重量数组，v 是价值数组，假设下标从 1 开始到 N
    
    // 1. 初始化 DP 表格 (大小开 N+1 行，W+1 列)
    // dp[i][j] 表示只考虑前 i 种物品，在容量限制为 j 的情况下，能装入的最大价值
    定义二维整数数组 dp[N+1][W+1] = {0}
    // 默认全填 0 即可，因为容量为 0 或 0 种物品时，能装的价值就是 0
    
    // 2. 核心状态转移
    FOR i = 1 TO N DO:
        FOR j = 1 TO W DO:
            
            // 选项 A：第 i 种物品比当前背包容量 j 还重，哪怕一件都装不下
            IF w[i] > j THEN
                dp[i][j] = dp[i-1][j]
                
            // 选项 B：能装得下，抉择“装”还是“不装”，取最大值
            ELSE
                // 不装：dp[i-1][j] (完全不拿第 i 种物品，继承上一层状态)
                // 装：当前物品价值 v[i] + 剩余容量能装的最大价值
                // 【注意核心区别】：这里是 dp[i][j - w[i]]，而不是 dp[i-1][j - w[i]]
                // 因为物品有无限件，拿了一件之后，剩余容量还可以继续从【当前第 i 种物品】中选
                dp[i][j] = max(dp[i-1][j], v[i] + dp[i][j - w[i]])
            END IF
            
        END FOR
    END FOR
    
    // 3. 计算大结局
    // dp[N][W] 就是 N 种物品在容量为 W 的背包里最多能装的价值
    max_value = dp[N][W]
    
    // 返回最大价值
    RETURN max_value
```


2.零钱兑换二
给你一个整数数组 `coins` 表示不同面额的硬币，另给一个整数 `amount` 表示总金额。 请你计算并返回可以凑成总金额的**硬币组合数**。如果任何硬币组合都无法凑出总金额，返回 `0`。
**假设每一种面额的硬币有无限个。**

【示例】

- **输入：** `amount = 5`, `coins = [1, 2, 5]`
    
- **输出：** `4`
    
- **解释：** 有四种方式可以凑成总金额： 5 = 5 5 = 2 + 2 + 1 5 = 2 + 1 + 1 + 1 5 = 1 + 1 + 1 + 1 + 1

反映在状态转移方程上，只有一个极其微小、但决定了整个宇宙规律的区别：

- **0-1 背包：** `dp[i][j] = dp[i-1][j] + dp[i-1][j - nums[i]]`
    
    （选了当前物品后，容量减少，但物品只能从**前 $i-1$ 个**里挑了，因为当前物品不能再用。）
    
- **完全背包：** `dp[i][j] = dp[i-1][j] + dp[i][j - coins[i]]`
    
    （选了当前硬币后，容量减少，但我们**依然可以从前 $i$ 个**硬币里挑，因为当前硬币可以继续被选中！）
    

也就是后半部分的下标，**从 `i-1` 变成了 `i`**

```c
Algorithm CoinChangeII(coins, amount):
    // coins 是硬币面额数组，假设下标从 1 开始到 N
    N = length(coins)
    
    // 1. 初始化 DP 表格 (大小开 N+1 行，amount+1 列)
    // dp[i][j] 表示使用前 i 种硬币，凑出金额 j 的组合数
    定义二维整数数组 dp[N+1][amount+1] = {0}
    
    // 关键初始化：凑出金额 0 的方法只有 1 种（什么硬币都不选）
    // 注意：无论有多少种硬币，只要目标是 0，方法数就是 1
    FOR i = 0 TO N DO:
        dp[i][0] = 1
    END FOR
    
    // 2. 核心状态转移
    // i 代表当前正在考虑第 i 种硬币
    FOR i = 1 TO N DO:
        
        // j 代表当前要凑的金额 (从 1 到 amount)
        FOR j = 1 TO amount DO:
            
            IF coins[i] > j THEN
                // 硬币面值比当前金额大，一枚都放不下，只能不用
                dp[i][j] = dp[i-1][j]
            ELSE
                // 组合数 = 不用当前硬币的组合数 + 用了当前硬币(且还能继续用)的组合数
                // 🚨 注意看加号后面的下标是 i，不是 i-1
                dp[i][j] = dp[i-1][j] + dp[i][j - coins[i]]
            END IF
            
        END FOR
    END FOR
    
    // 3. 大结局
    RETURN dp[N][amount]
```


3.组合总和 Ⅳ
给你一个由**不同**整数组成的数组 `nums` ，和一个目标整数 `target` 。请你从 `nums` 中找出并返回总和为 `target` 的元素组合的个数。 **题目强调：顺序不同的序列被视作不同的组合。**（换句话说，这道题实际上求的是**排列数**，不是组合数）。
【示例】

- **输入：** `nums = [1, 2, 3]`, `target = 4`
    
- **输出：** `7`
    
- **解释：** 所有可能的组合为： (1, 1, 1, 1) (1, 1, 2) (1, 2, 1) (2, 1, 1) (1, 3) (3, 1) (2, 2) 请注意，不同的顺序被视为不同的组合（比如 `(1, 3)` 和 `(3, 1)` 算两种）。

上一题（零钱兑换 II）求的是**组合数**，这题求的是**排列数**。 反映在代码里，就是两个 `for` 循环谁在外面、谁在里面的问题！

- **求组合数（外层物品，内层容量）**： 如果你先遍历硬币，比如第一轮循环只用面值为 `1` 的硬币，第二轮才加入面值为 `2` 的硬币。这样算出来的序列，永远是 `1` 在前面，`2` 在后面（比如 `1, 1, 2`）。它**绝对不可能**出现先用了 `2` 又回去选 `1` 的情况。这就天然去除了重复排列。
    
- **求排列数（外层容量，内层物品）**： 如果你先遍历目标容量（比如目标和为 `1, 2, 3...`），在每一个容量下，你都把所有的数字拿过来试一遍。 当目标和为 3 时，你可以用 `1+2`（最后一步用了数字 2）；也可以用 `2+1`（最后一步用了数字 1）。这就把**所有顺序不同**的情况全算进去了。

**底层逻辑等价于爬楼梯**： 这道题其实根本不需要往二维背包去想，它就是一道**升级版的爬楼梯问题**。 `target` 就是楼梯的总级数。`nums` 数组就是你每次能跨的步数。 问爬到楼梯顶有几种走法？—— 显然，先跨 1 步再跨 2 步，和先跨 2 步再跨 1 步是不同的走法。

```c
Algorithm CombinationSum4(nums, target):
    // nums 是可选的数字数组，假设下标从 1 开始到 N
    N = length(nums)
    
    // 1. 初始化一维 DP 表格 (大小开 target + 1)
    // dp[j] 表示凑成目标和为 j 的排列总数
    定义一维整数数组 dp[target + 1] = {0}
    
    // 边界条件：凑出和为 0 的排列数为 1（什么都不选）
    dp[0] = 1
    
    // 2. 核心状态转移
    // 🚨 陷阱警告：外层循环遍历背包容量 (目标和)
    FOR j = 1 TO target DO:
        
        // 内层循环：遍历物品 (数组元素)
        FOR i = 1 TO N DO:
            
            // 只要当前数字还能装得下，就把这个数字当做排列的最后一个元素
            IF nums[i] <= j THEN
                dp[j] = dp[j] + dp[j - nums[i]]
            END IF
            
        END FOR
        
    END FOR
    
    // 3. 大结局
    RETURN dp[target]
```

4.零钱兑换
给你一个整数数组 `coins` ，表示不同面额的硬币；以及一个整数 `amount` ，表示总金额。 计算并返回可以凑成总金额所需的 **最少的硬币个数** 。如果没有任何一种硬币组合能组成总金额，返回 `-1` 。 **假设每种硬币的数量是无限的。**

【示例 1】

- **输入：** `coins = [1, 2, 5]`, `amount = 11`
    
- **输出：** `3`
    
- **解释：** $11 = 5 + 5 + 1$ （最少需要 3 枚硬币）

- **背包容量**：总金额 `amount`。
    
- **物品**：硬币（无限次使用，所以是完全背包）。
    
- **物品重量**：硬币的面值 `coins[i]`。
    
- **物品价值**：这道题最特殊的地方在于，每个硬币的“价值”或者说“代价”都是 **1**（因为求的是硬币的个数）。
    
- **目标**：装满容量为 `amount` 的背包，使得总代价（个数）**最小**。
    

**状态转移方程**：
- **状态定义**：`dp[i][j]` 表示从前 `i` 种硬币中挑选，凑出总金额恰好为 `j`，所需要的最少硬币个数。
    
- **状态转移**：
    
    - 如果当前硬币装不下（`coins[i] > j`）：只能不选，完全继承前 `i-1` 种硬币的结果。 `dp[i][j] = dp[i - 1][j]`
        
    - **（核心高能预警 🚨）** 如果当前硬币装得下： 选项 A（不选）：`dp[i - 1][j]` 选项 B（选它）：当前选了 1 枚，因为硬币有无限个，选完之后，我们**依然可以继续从前 `i` 种硬币里选**去凑剩下的钱！ 所以，选项 B 是 `dp[i][j - coins[i]] + 1`，注意下标是 **`i`**，不是 `i-1`！ 最终：`dp[i][j] = min(dp[i - 1][j], dp[i][j - coins[i]] + 1)`

```c
Algorithm CoinChange_2D(coins, amount):
    // coins 是硬币面值数组，假设下标从 1 开始到 N
    N = length(coins)
    
    // 1. 初始化 DP 表格 (大小开 N+1 行，amount+1 列)
    // 同样，用 amount + 1 代表“无穷大”（凑不出来）
    定义二维整数数组 dp[N+1][amount+1] = {amount + 1}
    
    // 初始化第一列：当目标金额为 0 时，无论有多少种硬币，所需的个数都是 0
    FOR i = 0 TO N DO:
        dp[i][0] = 0
    END FOR
    
    // 2. 核心状态转移
    FOR i = 1 TO N DO:
        FOR j = 1 TO amount DO:
            
            IF coins[i] > j THEN
                // 装不下，硬币个数继承前 i-1 种的答案
                dp[i][j] = dp[i - 1][j]
            ELSE
                // 装得下，取“不选”和“选”的最小值
                // 🚨 请死死盯住这里的 dp[i]，这就是它能无限使用的灵魂所在
                dp[i][j] = min(dp[i - 1][j], dp[i][j - coins[i]] + 1)
            END IF
            
        END FOR
    END FOR
    
    // 3. 大结局
    IF dp[N][amount] == amount + 1 THEN
        RETURN -1  // 还是无穷大，说明无解
    ELSE
        RETURN dp[N][amount]
    END IF
```

5.完全平方数
【题目描述】 给你一个整数 `n` ，返回和为 `n` 的完全平方数的最少数量。 完全平方数是一个整数，其值等于另一个整数的平方（如 `1, 4, 9, 16, ...`）。

【示例 1】

- **输入：** `n = 12`
    
- **输出：** `3`
    
- **解释：** `12 = 4 + 4 + 4`
    

【示例 2】

- **输入：** `n = 13`
    
- **输出：** `2`
    
- **解释：** `13 = 4 + 9`

- **物品总数**：凑出数字 `n`，我们最多能用到的完全平方数是 $\lfloor\sqrt{n}\rfloor$ 的平方。假设 $M = \lfloor\sqrt{n}\rfloor$，那么我们就有 $M$ 个物品（分别是 $1^2, 2^2, \dots, M^2$）。
    
- **状态定义**：`dp[i][j]` 表示从前 `i` 个完全平方数（即 $1^2 \dots i^2$）中挑选，凑出数字 `j` 所需要的最少个数。
    
- **状态转移**：
    
    - 如果当前平方数装不下（$i^2 > j$）：只能不选，`dp[i][j] = dp[i-1][j]`
        
    - 如果装得下：取“不选”和“选”的最小值。因为是完全背包，选了之后**还能继续选**第 `i` 个平方数，所以是：
        
        `dp[i][j] = min(dp[i-1][j], dp[i][j - i*i] + 1)`
        
        （🚨 再一次盯住这个 `dp[i]` ，这就是完全背包的二维标志）


```c
Algorithm NumSquares_2D(n):
    
    // 0. 前置计算：确定物品的种类数 M
    // 也就是求 n 的平方根并向下取整
    M = floor(sqrt(n))
    
    // 1. 初始化 DP 表格 (大小开 M+1 行，n+1 列)
    // 最多用 n 个 1 相加，所以 n+1 就代表逻辑上的无穷大
    定义二维整数数组 dp[M + 1][n + 1] = {n + 1}
    
    // 初始化第一列：当目标数字为 0 时，不管用几种平方数，需要的个数都是 0
    FOR i = 0 TO M DO:
        dp[i][0] = 0
    END FOR
    
    // 2. 核心状态转移
    // i 代表当前正在考虑第 i 个完全平方数
    FOR i = 1 TO M DO:
        
        // 计算当前“物品”的重量
        weight = i * i
        
        // j 代表当前的目标数字 (从 1 到 n)
        FOR j = 1 TO n DO:
            
            // 选项 A：当前的平方数太大了，数字 j 装不下
            IF weight > j THEN
                dp[i][j] = dp[i - 1][j]
                
            // 选项 B：装得下，二选一取最小
            ELSE
                // 不选：dp[i-1][j]
                // 选了：再加 1 个，并且还能继续用前 i 个平方数（所以是 dp[i]）
                dp[i][j] = min(dp[i - 1][j], dp[i][j - weight] + 1)
            END IF
            
        END FOR
        
    END FOR
    
    // 3. 大结局
    // 从 M 种平方数里挑，凑出数字 n 的最少个数
    RETURN dp[M][n]
```
